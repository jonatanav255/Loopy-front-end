# Loopy — Front End

## Run

```bash
# 1. Install dependencies
npm install

# 2. Start the dev server (http://localhost:5173)
npm run dev
```

Requires Node.js 18+ and the backend running on port 8080.

## Rules for Claude

- After every change or phase, the application must compile and run successfully.
- If tests exist, all tests must pass before considering any work done.
- Never leave the codebase in a broken state.
- Run `npm run build` to verify before finishing any task.
